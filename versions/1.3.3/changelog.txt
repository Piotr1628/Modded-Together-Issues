# Patch Notes — 1.3.3 Update
> New content, balance changes, bug fixes & more

[![image](https://media.forgecdn.net/attachments/1295121/changelog/changelog_2daa25df-56a3-48ef-95a8-980e4924a04c.png)](https://wabbanode.com/partner/moddedtogether)

## ✦ New Content

- Added **Create Vibrant Vaults**
- Added **Oracle Index** — in-game manual for Simply Swords and Oritech
- Added **Simply Swords** as loot in Dungeons Arise and Seven Seas
- **Simply Swords** abilities reworked — every weapon now functions differently
- **Capturing** enchant returned
- Blowing up an **Apothic Spawner** now drops **Spawner Chains**, used to craft **Spawner Runes** for upgrading spawners
- **Apotheosis** received a visual update
- Added Create optimization mod — should reduce lag on both server and client

## ↻ Updates

- **Runestone Slag** must now be crushed before use
- Various recipe changes
- Updated many mods and NeoForge to the latest version

## ✔ Bug Fixes

- Fixed **Pillager** crossbows not dealing damage
- Fixed **Runic Weapons** recipes
- Rolled back **Better End** update — Biomes We've Gone biomes were not generating correctly

## − Removals

- Removed **Effortless Building** — caused crashes
